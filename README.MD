# 🎭 Endless Installer Prank

A harmless prank script that simulates a never-ending software installation process. Perfect for pranking your friends, coworkers, or anyone who thinks their system is being updated!

> **Note**: This README documents the concept and specifications for an endless installer prank script. The actual script implementation can be created in any language (Bash, Python, JavaScript, etc.) following the guidelines described below.

## 🎯 What Is This?

This is a **prank script** that creates the illusion of a legitimate software installation process. It looks completely real, but it's all just for show - nothing is actually being installed or modified on your system.

### 🎪 Realistic Installation Simulation
- **Professional appearance**: Looks like a serious install and configuration job
- **Progress bar**: Shows a progress bar that slowly crawls toward the high 90s (95-99%) and then hangs there indefinitely
- **Convincing logs**: Continuously prints realistic installation logs including:
  - Python package installations
  - Node.js modules
  - System plugins
  - Service configurations
  - Health checks and diagnostics
  - Dependency resolutions

### ✅ Completely Safe
- **No actual installations**: Never installs anything on your system
- **No system modifications**: Does not touch any system files or configurations
- **No reboots**: Never restarts your computer
- **No admin rights needed**: Runs with regular user permissions
- **Easy to stop**: Simply close the window or press `Ctrl+C` to terminate

## 🚀 How It Works

The script creates a fake installation experience by:

1. **Displaying a progress bar** that moves slowly from 0% to the high 90s
